## Finding

### P1: Owner SQL bypasses the allocated loopback endpoint

Location: `tools/e-rehearsal/rehearse.py:63-67` (guard at lines 70-79).

The allocation declares a single `host-loopback` host/port and validates the
importer URL against it. However, every owner SQL command instead executes
`psql` inside the Compose postgres service without `-h` or `-p`. This connects
through that container's default socket/connection settings, never through the
allocated endpoint. The allocation host and port do not occur in this command.
Container PG environment settings are also not cleared. The database name,
role and reusable synthetic comment checked by guard do not prove that this
is the same PostgreSQL authority reached by the importer and runtime probes.

A misbound host port and a Compose service containing a copied database with
the same name/comment can therefore pass the owner guard against one cluster
while the importer/probes reach another. In particular, remove-receipts can
drop the seven receipt tables in the Compose-selected cluster despite the
allocation only authorizing the host-loopback endpoint. The exact marked-table
and RESTRICT transaction checks do not repair this authority mismatch.

Offline reproduction: patched only `rehearse.command` to capture its arguments,
set the same allocation to port 25432, called `sql("SELECT 1")`, changed its port
to 25433, and called it again. Both commands were identical. Captured command:

```text
docker --context desktop-linux compose -p synthetic-qa-zns-guard
  -f reviewed-compose.yaml --env-file reviewed-images.env exec -T postgres
  psql -X -A -t -U postgres -d synthetic_qa_zns_guard -v ON_ERROR_STOP=1
```

Use the validated allocated endpoint for owner SQL too, with explicit target
and transport settings and no inherited PG/service/hostaddr indirection.
Alternatively, define and independently validate an explicit additional
transport contract before allowing its executor; the current contract permits
only host-loopback. Add focused rejection tests proving that an unbound
Compose socket/other authority cannot reach the owner executor or deletion.
