# Order-review saved-decision presentation

The Mini App separates the title from the complete literal terms of a saved
order-payment review. It removes only the enclosing backtick fence generated by
`renderOrderReviewSummary`. The body uses the normal page font and wraps at narrow
widths. Unknown summary formats remain visible verbatim.

All amounts, frozen order lines, charges, capacity notes, identity references,
reason and deadlines remain in the saved summary. Technical IDs remain available
for reconciliation. This change does not parse arbitrary Markdown or HTML, change
confirmation arguments, or retranslate frozen terms when the UI language changes.
