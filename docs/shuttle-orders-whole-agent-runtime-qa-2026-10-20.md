and two owners. Event/catalog configuration, authorities and assigned unpaid
passes are explicit prerequisites. No order, preparation, evidence, allocation
or review is seeded. This is not another fresh registration/pass-assignment gate.

module reads/writes through a controlled provider. Each owner discovers the event,
reads the catalog and saved selection, calculates the complete quote, saves the

There is no order before consent. Explicit untagged free-text consent resolves
the original input/approval/argument hash. The submitted and persisted snapshot
matches that exact preparation; the consumed draft is cleared once.

Three distinct valid PDFs enter normal bot intake. Original task/inbox requests,
file IDs, Telegram timestamps and captions are retained. Each exact file ID and
caption reaches the actual model request. Owner file fetch and authorized reviewer
fetch return artifacts whose SHA-256 and size match the original PDF. This proves
protected file transfer, not unattended interpretation of payment-document content.

The first claim is pending and holds two places. The competing second claim is
exhausted and holds none. No claim alone confirms money. The ambassador reads
current evidence and proof, saves the full decision and waits for explicit consent.
Delivered decision descriptions and independent original timestamps, identities,
amounts, reasons and capacity effects are checked before consent.

The ambassador rejects the first claim, releasing its two places and crediting

The ambassador explicitly rejects that claim too. Its owner submits a new PDF and
claim, holds the released places, and the ambassador explicitly confirms25.68 BYN.
Confirmation occupies those two places; it performs no refund or fulfillment.

reply; there are zero orders, evidence, allocations or reviews. The corrected
